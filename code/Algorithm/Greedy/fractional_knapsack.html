Fractional Knapsack

Choose items to maximize total value without exceeding a bag's capacity. In the fractional version, you may take a fraction of an item. The greedy strategy is to take items in descending order of value ÷ weight.

Important: this greedy strategy is optimal for Fractional Knapsack. It is not generally optimal for 0/1 Knapsack, where each item must be taken whole or not at all.

3. Sort items by value-to-weight ratio

Before filling the bag, calculate each ratio. The largest ratio is considered first. When ratios tie, this simulator uses the original item order as a consistent tie-breaker.

Greedy rankItemWeightValueRatio
Example: if an item is worth 60 and weighs 10, its ratio is 60 ÷ 10 = 6 value units per weight unit. A higher ratio gives more value for each unit of capacity.

6. Python implementation

This implementation uses the same greedy rule as the simulator. It returns the selected fraction of each item, total weight used, and total value.

def fractional_knapsack(items, capacity):
    # Each item: {"name": "A", "weight": 10, "value": 60}
    # Sort by value per unit of weight, highest first.
    items = sorted(
        items,
        key=lambda item: item["value"] / item["weight"],
        reverse=True
    )

    total_value = 0
    weight_used = 0
    selections = []

    for item in items:
        if capacity <= 0:
            break

        weight = item["weight"]
        value = item["value"]

        # Take the whole item if it fits; otherwise take a fraction.
        fraction = min(1, capacity / weight)
        taken_weight = fraction * weight
        gained_value = fraction * value

        selections.append({
            "name": item["name"],
            "fraction": fraction,
            "weight_taken": taken_weight,
            "value_gained": gained_value
        })

        capacity -= taken_weight
        weight_used += taken_weight
        total_value += gained_value

    return selections, weight_used, total_value


items = [
    {"name": "A", "weight": 10, "value": 60},
    {"name": "B", "weight": 20, "value": 100},
    {"name": "C", "weight": 30, "value": 120}
]

selected, used, value = fractional_knapsack(items, capacity=50)
print("Weight used:", used)
print("Maximum value:", value)
for item in selected:
    print(item)







7. Complexity and when to use it


    

  • Sorting: O(n log n), where n is the number of items.
    • 

  • Selection after sorting: O(n).
    • 

  • Overall time: O(n log n), dominated by sorting.
    • 

  • Extra space: O(n) in this implementation because a sorted copy and selection results are stored.
    • 

  • Use it when: items can be divided, such as allocating divisible resources to maximize value.
    • 



Remember the steps: calculate each ratio → sort high to low → take whole items while possible → take the needed fraction of the next item → stop when capacity is full or items run out.
