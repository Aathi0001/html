Huffman Coding

Build a binary tree by repeatedly combining the two least-frequent nodes. The resulting tree gives frequent characters shorter binary codes.

1. The main idea

InputCharactersEach character has a frequency.
Greedy choiceTwo smallestCombine the two lowest frequencies.
OutputBinary codesFollow left/right edges from root to leaf.

Convention used here: left edge = 0, right edge = 1. When frequencies tie, more than one valid Huffman tree may exist.

5. Python implementation

This version uses a min-heap. A counter is included to break ties deterministically without trying to compare dictionary nodes.

import heapq
from itertools import count

def huffman_codes(frequencies):
    serial = count()
    heap = []

    for character, frequency in frequencies.items():
        node = {"char": character, "left": None, "right": None}
        heapq.heappush(heap, (frequency, next(serial), node))

    while len(heap) > 1:
        f1, _, left = heapq.heappop(heap)
        f2, _, right = heapq.heappop(heap)

        parent = {
            "char": None,
            "left": left,
            "right": right
        }
        heapq.heappush(heap, (f1 + f2, next(serial), parent))

    root = heap[0][2]
    codes = {}

    def walk(node, code):
        if node["left"] is None and node["right"] is None:
            codes[node["char"]] = code or "0"
            return
        walk(node["left"], code + "0")
        walk(node["right"], code + "1")

    walk(root, "")
    return codes

frequencies = {"A": 5, "B": 9, "C": 12,
               "D": 13, "E": 16, "F": 45}
print(huffman_codes(frequencies))

  
Exact code assignments can differ when equal frequencies are resolved differently. The encoded length remains optimal for the given frequencies.

How to decode: Huffman codes are prefix-free, meaning no character's code is the beginning of another character's code. Read bits from the root until reaching a leaf, output that character, then return to the root.

 


 

  
7. Complexity and when to use it

  
    
   
  • Tree construction: O(n log n) using a min-heap, where n is the number of distinct characters.
    • 
   
  • Generating all codes: O(n) for a tree with n leaves.
    • 
   
  • Space: O(n) for the tree and heap.
    • 
   
  • Use it for: lossless compression when symbol frequencies are known or can be estimated.
    • 
   
  • Remember: Huffman coding compresses data; it is not encryption.
