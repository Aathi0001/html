Greedy Algorithms · Lesson 03

Activity Selection Problem

Given activities with start and finish times, choose the largest possible set of activities that do not overlap. The classic greedy strategy is to always select the compatible activity that finishes earliest.

1. The main idea

InputStart + finishEach activity occupies a time interval.
Greedy choiceFinish earliestSort by finish time, smallest first.
GoalMore activitiesChoose the maximum compatible set.

In this lesson, an activity starting exactly when the previous one finishes is allowed. The compatibility rule is start time ≥ last selected finish time.

6. Python implementation

This implementation sorts activities by finish time and selects an activity only when it starts at or after the finish time of the last selected activity.

def activity_selection(activities):
    # Each activity is: (name, start, finish)
    activities = sorted(activities, key=lambda a: (a[2], a[1]))
    selected = []
    last_finish = float("-inf")

    for name, start, finish in activities:
        if start >= last_finish:
            selected.append((name, start, finish))
            last_finish = finish

    return selected


activities = [
    ("A1", 1, 4),
    ("A2", 3, 5),
    ("A3", 0, 6),
    ("A4", 5, 7),
    ("A5", 3, 9),
    ("A6", 5, 9),
    ("A7", 6, 10),
    ("A8", 8, 11),
    ("A9", 8, 12),
    ("A10", 2, 14),
    ("A11", 12, 16)
]

chosen = activity_selection(activities)
print("Selected activities:")
for activity in chosen:
    print(activity)

8. Complexity and when to use it


    

  • Sorting: O(n log n).
    • 

  • Selection pass: O(n).
    • 

  • Overall time: O(n log n), dominated by sorting.
    • 

  • Space: O(n) for the sorted list and selected result in this implementation.
    • 

  • Use it for: scheduling the maximum number of non-overlapping meetings, jobs, or events when each has a start and finish time.
    • 



Remember: sort by finish time—not start time or duration. Pick the earliest-finishing compatible activity, then repeat.
