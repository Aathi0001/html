Topological Sort (Kahn’s Algorithm)

Order dependencies before the tasks that need them. Learn the idea, trace operations, and connect the trace to Python.

Standalone · Offline

1. Core idea

Produce a linear order of a directed acyclic graph so every edge u→v places u before v.

Main structure: In-degree counts + queue

2. When should I use it?

  • Task scheduling and prerequisites
  • Build/dependency ordering
  • Detecting whether a directed graph contains a cycle

3. Understand the example graph

Teaching example. Follow the exact values in the dry run. Weighted algorithms use edge costs; MST algorithms use undirected edges.

Interactive dry run

Each click performs one meaningful teaching step. Inspect the data state and predict what should happen next.

Step 1 of 6

1. Calculate in-degree

A has no incoming edges, B and C have one each, and D has two.

indegree = {A:0, B:1, C:1, D:2} queue = [A] order = []

2. Remove A

Output A; B and C each lose one incoming edge.

queue = [B,C] indegree = {A:0, B:0, C:0, D:2} order = [A]

3. Remove B

Output B. D's in-degree decreases from 2 to 1.

queue = [C] indegree[D] = 1 order = [A,B]

4. Remove C

Output C. D's in-degree reaches zero, so enqueue D.

queue = [D] indegree[D] = 0 order = [A,B,C]

5. Remove D

Output D. No outgoing edges remain.

queue = [] order = [A,B,C,D]

6. Check result

All vertices were output, so the graph is acyclic.

topological order = [A,B,C,D]

4. Python implementation

Compare each variable in the code with the data state shown in the dry run.

from collections import deque

def topological_sort(graph):
    indegree = {node: 0 for node in graph}
    for node in graph:
        for neighbour in graph[node]:
            indegree[neighbour] += 1
    queue = deque(node for node in graph if indegree[node] == 0)
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            indegree[neighbour] -= 1
            if indegree[neighbour] == 0:
                queue.append(neighbour)
    if len(order) != len(graph):
        raise ValueError("Graph contains a directed cycle")
    return order

5. Complexity

TimeO(V + E)
Extra spaceO(V)

These are standard bounds for the implementation shown; representation and data structures can change the exact bound.

6. Common mistake

A topological order exists only for a DAG. Different valid orders may be possible.

7. Quick check

What if fewer than V vertices are added to the topological order?

The directed graph contains a cycle, so it is not a DAG and no topological ordering exists.
