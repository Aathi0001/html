Dijkstra’s Algorithm

Single-source shortest paths with non-negative weights. Learn the idea, trace operations, and connect the trace to Python.

Standalone · Offline

1. Core idea

Find the cheapest distance from one start vertex to every reachable vertex. Repeatedly select the unsettled vertex with the smallest tentative distance and relax its edges.

Main structure: Distance map + min-priority queue

2. When should I use it?

  • Road/network routes with non-negative costs
  • Minimum travel cost from one source
  • Weighted graphs without negative edges

3. Understand the example graph

Teaching example. Follow the exact values in the dry run. Weighted algorithms use edge costs; MST algorithms use undirected edges.

Step 1 of 5

1. Initialize

Set the start distance to 0; all others are infinity.

dist = {A:0, B:∞, C:∞, D:∞, E:∞} heap = [(0,A)]

2. Settle A

A→B costs 1 and A→D costs 4.

dist = {A:0, B:1, C:∞, D:4, E:∞} heap = [(1,B), (4,D)]

3. Settle B

B→C gives 3. B→D gives 2, improving D from 4 to 2.

dist = {A:0, B:1, C:3, D:2, E:∞} heap = [(2,D), (3,C), (4,D stale)]

4. Settle D

D→E gives 4. No route back to A or B improves them.

dist = {A:0, B:1, C:3, D:2, E:4}

5. Finish

C cannot improve E, and E is settled. Distances are final.

final distances: A=0, B=1, C=3, D=2, E=4 shortest A→E: A→B→D→E (cost 4)

4. Python implementation

Compare each variable in the code with the data state shown in the dry run.

import heapq
from math import inf

def dijkstra(graph, start):
    dist = {node: inf for node in graph}
    parent = {node: None for node in graph}
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        current, node = heapq.heappop(heap)
        if current != dist[node]:
            continue

        for neighbour, weight in graph[node]:
            if weight < 0:
                raise ValueError("Dijkstra needs non-negative weights")
            candidate = current + weight
            if candidate < dist[neighbour]:
                dist[neighbour] = candidate
                parent[neighbour] = node
                heapq.heappush(heap, (candidate, neighbour))

    return dist, parent

5. Complexity

TimeO((V + E) log V)
Extra spaceO(V + E)

These are standard bounds for the implementation shown; representation and data structures can change the exact bound.

6. Common mistake

Do not use Dijkstra when negative-weight edges exist. Use Bellman–Ford for that case.

7. Quick check

Can Dijkstra be used safely if one edge has weight −3?

No. Dijkstra requires non-negative edge weights; use Bellman–Ford when negative edges are allowed.
