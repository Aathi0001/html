Depth-First Search (DFS)

Follow a branch deeply, then backtrack. Learn the idea, trace operations, and connect the trace to Python.

Standalone · Offline

1. Core idea

Explore as far as possible along one branch before returning to try another branch. DFS can be written recursively or with an explicit stack.

Main structure: Recursion stack or explicit stack

2. When should I use it?

  • Maze exploration and backtracking
  • Cycle and connectivity analysis
  • Graph components and traversal

Step 1 of 6

1. Enter A

Mark A visited. B appears before D in A's neighbour list, so go to B first.

visited = {A} order = [A] call stack = [A]

2. Enter B

A is already visited. Continue deeper to C.

visited = {A, B} order = [A, B] call stack = [A, B]

3. Enter C

B is visited. Continue to E.

visited = {A, B, C} order = [A, B, C] call stack = [A, B, C]

4. Enter E

C is visited. Continue to D.

visited = {A, B, C, E} order = [A, B, C, E] call stack = [A, B, C, E]

5. Enter D

A, B and E are already visited. D has no unvisited neighbour, so return.

visited = {A, B, C, D, E} order = [A, B, C, E, D] call stack = [A, B, C, E, D] → return

6. Backtrack

Return through E, C, B and A. Every reachable vertex has been visited.

final order = [A, B, C, E, D] recursion complete

4. Python implementation

Compare each variable in the code with the data state shown in the dry run.

def dfs(graph, start):
    visited = set()
    order = []

    def visit(node):
        visited.add(node)
        order.append(node)

        for neighbour in graph[node]:
            if neighbour not in visited:
                visit(neighbour)

    visit(start)
    return order

graph = {
    "A": ["B", "D"],
    "B": ["A", "C", "D"],
    "C": ["B", "E"],
    "D": ["A", "B", "E"],
    "E": ["C", "D"]
}
print(dfs(graph, "A"))

5. Complexity

TimeO(V + E)
Extra spaceO(V)

These are standard bounds for the implementation shown; representation and data structures can change the exact bound.

6. Common mistake

The exact visit order depends on neighbour ordering. DFS does not automatically find a shortest path.

7. Quick check

Why does DFS return to a previous node after reaching a dead end?

It backtracks when the current node has no unvisited neighbour, allowing another branch to be explored.
