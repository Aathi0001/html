1. What is a graph?

A graph is a set of vertices (nodes) and edges (connections), written as G = (V, E).

Example undirected weighted graph. The number beside an edge is its cost. For BFS and DFS, ignore weights.

TermMeaningExample
VertexA node in the graphA, B, C
EdgeA connection between verticesA–B
WeightCost, distance or time on an edgeA–B costs 1
Directed edgeA one-way connectionA → B
PathA sequence of connected verticesA → B → D
CycleA path that returns to its startA → B → A

2. Adjacency list

Each vertex stores the neighbours directly connected to it. This representation is common for sparse graphs.

graph = {
    "A": ["B", "D"],
    "B": ["A", "C", "D"],
    "C": ["B", "E"],
    "D": ["A", "B", "E"],
    "E": ["C", "D"]
}

3. Big-O notation

V is the number of vertices; E is the number of edges.

O(V + E) grows with vertices and connections. O(V²) often means considering every possible pair.

With an adjacency list, BFS and DFS take O(V + E) because each reachable vertex and edge is examined a bounded number of times.
