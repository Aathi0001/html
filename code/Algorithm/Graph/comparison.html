Shortest path

Find the least-cost route between vertices.

  • BFS: unweighted
  • Dijkstra: non-negative weights
  • Bellman–Ford: negative edges
  • Floyd–Warshall: all pairs

Minimum spanning tree

Connect every vertex while minimising total chosen edge weight.

  • Kruskal: globally sort edges
  • Prim: grow one tree from a start

Decision checklist

  1. Ordering prerequisites in a DAG? Topological sort.
  2. Connecting every vertex at minimum total cost? Kruskal or Prim.
  3. Unweighted shortest path? BFS.
  4. One-source shortest distances with non-negative weights? Dijkstra.
  5. Shortest paths with negative edges? Bellman–Ford.
  6. Shortest distances for every pair in a graph small enough for cubic work? Floyd–Warshall.
