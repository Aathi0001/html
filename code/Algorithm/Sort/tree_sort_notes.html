Tree Sort

Insert values into a binary search tree, then read them using in-order traversal.

● Learn by tracing
Binary search treeIn-order traversalAverage O(n log n)Can degrade to O(n²)

1The idea

  1. Insert each value into a binary search tree (BST).
  2. Smaller values go left; larger values go right.
  3. Store duplicate occurrences with a count.
  4. Traverse left subtree, node, then right subtree.
  5. That in-order traversal produces ascending order.
Memory hook: BST in-order traversal visits values from smallest to largest.

2Complete Python code

class Node:
    def __init__(self, value):
        self.value = value
        self.count = 1
        self.left = None
        self.right = None

def tree_sort(values):
    root = None

    def insert(node, value):
        if node is None:
            return Node(value)
        if value < node.value:
            node.left = insert(node.left, value)
        elif value > node.value:
            node.right = insert(node.right, value)
        else:
            node.count += 1
        return node

    for value in values:
        root = insert(root, value)

    result = []
    def inorder(node):
        if node is None:
            return
        inorder(node.left)
        result.extend([node.value] * node.count)
        inorder(node.right)

    inorder(root)
    return result

print(tree_sort([5, 3, 8, 1, 2]))

Expected output

[1, 2, 3, 5, 8]

The function is written to be runnable as-is. Try changing the sample input and trace the algorithm again.

5Read the important lines

Node fields

Each node stores a value, duplicate count, and left/right child references.

insert(node, value)

Compare with the current node and recursively choose left or right.

node.count += 1

Keep repeated values at the same node while preserving their multiplicity.

inorder(node.left), node, inorder(node.right)

Visit left subtree, current value, then right subtree to get ascending order.

6When should you use it?

Good fit

  • You also need a search-tree structure for other operations.
  • A balanced BST is used to keep height controlled.

Be careful when

  • A plain unbalanced BST on already sorted input can become a chain.
  • When a simple built-in sorted() is sufficient.
