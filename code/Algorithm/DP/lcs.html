Longest Common Subsequence (LCS)

Find the longest sequence common to two strings in the same order, not necessarily contiguously.

Core idea

Let dp[i][j] be the LCS length of prefixes a[:i] and b[:j]. Matching characters use diagonal + 1; otherwise use max(top, left).

When to use

Use to compare sequences where characters can be skipped, such as diff tools, version comparison, and sequence analysis.

Example problem

A = 'ABC', B = 'AC'. The LCS is 'AC', with length 2.

Learning goal: understand what each DP state means, how a transition updates it, and how the final answer is read.

Python implementation

Connect each loop to the transition described in the dry run.

def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]

Complexity

Time O(m × n), space O(m × n). Length-only computation can use O(min(m,n)) space.

Common mistake

A subsequence may skip characters. A substring must be contiguous, so Longest Common Substring is a different problem.
