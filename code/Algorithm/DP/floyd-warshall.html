Intermediate

Floyd–Warshall

Compute shortest-path distances between every pair of vertices with dynamic programming.

Core idea

For each intermediate vertex k, improve dist[i][j] by checking whether i→k→j is shorter than the current route.

When to use

Use for all-pairs shortest paths, especially small or medium dense graphs. Negative edge weights are allowed, but negative cycles are not.

Example problem

Directed edges: A→B = 3, A→C = 10, B→C = 2. The shortest A→C route costs 5 via B.

Learning goal: understand what each DP state means, how a transition updates it, and how the final answer is read.

Python implementation

Connect each loop to the transition described in the dry run.

def floyd_warshall(dist):
    n = len(dist)
    dist = [row[:] for row in dist]

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(
                    dist[i][j],
                    dist[i][k] + dist[k][j]
                )

    if any(dist[i][i] < 0 for i in range(n)):
        raise ValueError("Negative cycle detected")
    return dist

Complexity

Time O(V³), space O(V²).

Common mistake

The intermediate-vertex loop k must be outermost. Represent infinity consistently and check for negative cycles.
