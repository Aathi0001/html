DP comparison

Compare common DP patterns, typical complexity, and when to use each one.

ProblemTypical complexityUse whenStudy
0/1 KnapsackTime O(n × capacity), space O(n × capacity)Use when every item has a weight and value, each item can be taken or skipped, and total weight must stay within a capacity.Lesson
Longest Common Subsequence (LCS)Time O(m × n), space O(m × n)Use to compare sequences where characters can be skipped, such as diff tools, version comparison, and sequence analysis.Lesson
Longest Increasing Subsequence (LIS)The basic DP is O(n²) time and O(n) spaceUse to find an increasing chain of values in an array, including sequence and ranking problems.Lesson
Matrix Chain MultiplicationTime O(n³), space O(n²), where n is the number of matricesUse when multiplying compatible matrices and the order of pairwise multiplication can be chosen.Lesson
Floyd–WarshallTime O(V³), space O(V²)Use for all-pairs shortest paths, especially small or medium dense graphs. Negative edge weights are allowed, but negative cycles are not.Lesson

Pattern reminders

  • Knapsack: item index + remaining capacity.
  • LCS: two prefix lengths.
  • LIS: best increasing subsequence ending at each index.
  • Matrix chain: interval of matrices and a split point.
  • Floyd–Warshall: source, destination, and allowed intermediate vertices.
