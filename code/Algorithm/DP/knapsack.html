0/1 Knapsack

Choose each item at most once to maximize value within a weight limit.

Core idea

Let dp[i][w] be the best value using the first i items with capacity w. Either skip item i, or take it once if it fits.

When to use

Use when every item has a weight and value, each item can be taken or skipped, and total weight must stay within a capacity.

Example problem

Items A=(weight 1,value 1), B=(3,4), C=(4,5), D=(5,7). Capacity = 7.

Learning goal: understand what each DP state means, how a transition updates it, and how the final answer is read.

Interactive dry run

Each click is one separate step. Use Previous and Next to inspect the state and explanation.

Python implementation

Connect each loop to the transition described in the dry run.

def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        weight, value = weights[i - 1], values[i - 1]
        for cap in range(capacity + 1):
            dp[i][cap] = dp[i - 1][cap]  # skip item
            if weight <= cap:
                take = value + dp[i - 1][cap - weight]
                dp[i][cap] = max(dp[i][cap], take)

    return dp[n][capacity]

Complexity

Time O(n × capacity), space O(n × capacity). A 1D DP array can reduce space to O(capacity).

Common mistake

In 0/1 Knapsack, each item is usable once. With a 1D array, iterate capacities backward to avoid reusing the current item.
