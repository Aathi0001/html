Longest Increasing Subsequence (LIS)

Find the longest strictly increasing subsequence while allowing gaps in the input.

Core idea

The O(n²) DP defines dp[i] as the LIS length ending at i. For each earlier j with nums[j] < nums[i], try extending dp[j].

When to use

Use to find an increasing chain of values in an array, including sequence and ranking problems.

Example problem

Array = [3, 1, 2, 5, 4]. One LIS is [1, 2, 4], with length 3.

Learning goal: understand what each DP state means, how a transition updates it, and how the final answer is read.

Interactive dry run

Each click is one separate step. Use Previous and Next to inspect the state and explanation.

Python implementation

Connect each loop to the transition described in the dry run.

def lis_length(nums):
    if not nums:
        return 0

    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)

Complexity

The basic DP is O(n²) time and O(n) space. A binary-search method computes the length in O(n log n).

Common mistake

A subsequence is not necessarily contiguous. For a strictly increasing sequence use <, not <=.
