Matrix Chain Multiplication

Choose parentheses to minimize scalar multiplications without changing matrix order.

Core idea

Let dp[i][j] be the minimum cost for multiplying matrices i through j. Try every split k between i and j.

When to use

Use when multiplying compatible matrices and the order of pairwise multiplication can be chosen.

Example problem

p = [10, 30, 5, 60] means A1 is 10×30, A2 is 30×5, and A3 is 5×60.

Learning goal: understand what each DP state means, how a transition updates it, and how the final answer is read.

Python implementation

Connect each loop to the transition described in the dry run.

def matrix_chain_order(p):
    # A_i has dimensions p[i-1] x p[i].
    n = len(p) - 1
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float("inf")
            for k in range(i, j):
                cost = (dp[i][k] + dp[k + 1][j]
                        + p[i] * p[k + 1] * p[j + 1])
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][n - 1]

Complexity

Time O(n³), space O(n²), where n is the number of matrices.

Common mistake

The dimensions determine the cost. Do not reorder matrices; only change the parentheses.
