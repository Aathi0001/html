1. The idea in one minute

Suppose you are searching for a pattern inside a larger text. When several characters match and then a mismatch happens, a naive algorithm may start over and compare characters it already learned about.

KMP avoids those unnecessary comparisons. It builds an array called LPS and uses it to decide where to continue in the pattern after a mismatch. The text pointer never moves backward.

Text

The full string being searched.

ABABABC

Pattern

The smaller string to find.

Core takeaway: on a mismatch, KMP uses previous matches in the pattern instead of moving the text pointer backward or restarting from scratch.

2. Prefix, suffix, and LPS

A prefix starts at the beginning of a string. A suffix ends at the end. A proper prefix is any prefix except the whole string.

LPS means Longest Proper Prefix which is also a Suffix. Each LPS entry answers: “For the pattern substring ending at this position, what is the length of its longest matching proper prefix and suffix?”

SubstringMatching proper prefix / suffixLPS
ANone0
ABNone0
ABAA1
ABABAB2
ABABCNone0

So ABABC has LPS array [0, 0, 1, 2, 0].

LPS values are lengths, not character indexes. If lps[j - 1] = 2, KMP can continue with two pattern characters already accounted for.

5. Python code

There are two functions: one builds the LPS array, and the other uses it to search for the first occurrence.

def build_lps(pattern):
    lps = [0] * len(pattern)
    length = 0
    i = 1

    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length != 0:
            # Try a shorter known prefix/suffix.
            length = lps[length - 1]
        else:
            lps[i] = 0
            i += 1

    return lps


def kmp_search(text, pattern):
    if pattern == "":
        return 0

    lps = build_lps(pattern)
    i = 0  # pointer in text
    j = 0  # pointer in pattern

    while i < len(text):
        if text[i] == pattern[j]:
            i += 1
            j += 1

            if j == len(pattern):
                return i - j
        elif j != 0:
            j = lps[j - 1]
        else:
            i += 1

    return -1


text = "ABABABC"
pattern = "ABABC"
print(kmp_search(text, pattern))  # 2
Important: this version returns the first match only. It returns -1 if the pattern is not found, and 0 for an empty pattern.

6. Understand the two mismatch cases

Case A — j is not zero

Some pattern characters already matched. Set j = lps[j - 1]. Keep i unchanged so the current text character is compared again with the new pattern position.

Case B — j is zero

No pattern prefix matched. There is nothing to reuse, so advance i to the next text character.

Full match

When j == len(pattern), the start index is i - j.

Common bug: after a mismatch with j != 0, do not increment i. KMP needs to compare the same text character against the fallback pattern position.

7. Complexity and when to use it

WorkTimeExtra space
Build LPSO(m)O(m)
Search textO(n)O(1) beyond the LPS array
TotalO(n + m)O(m)

n = text length, m = pattern length.

Use KMP when…

You want predictable linear-time searching, especially when patterns contain repeated prefix/suffix structures.

Compare with Naive

Naive searching can take O(n × m) in the worst case. KMP preprocesses the pattern to avoid redundant comparisons.

Remember

The text pointer never moves backward; the LPS array tells the pattern pointer how to fall back.

8. Quick self-test

1. What does LPS stand for?

Longest Proper Prefix which is also a Suffix.

2. What is the LPS array for ABABC?

[0, 0, 1, 2, 0].

3. On mismatch, when j is greater than zero, what changes?

Set j = lps[j - 1]. Keep the text pointer i in place for that comparison.

4. What is KMP's total time complexity?

O(n + m), where n is the text length and m is the pattern length.

5. What does the search function return if no match exists?

-1.
