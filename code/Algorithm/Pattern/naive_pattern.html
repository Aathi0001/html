1. What is pattern matching?

Given a text T and a pattern P, find every starting index where P occurs inside T. In this document, indices are zero-based.

Text

The larger string you search inside, for example ABABABC.

Pattern

The smaller string to find, for example ABABC.

Result

Return the start index or all matching indices. Example: ABABC starts at index 2.

Important: searching for a pattern means checking character sequences, not just whether the individual characters appear somewhere in the text.

3. Naive pattern searching

Naive searching tries every possible starting position in the text. At each position, it compares the pattern characters from left to right. If a character differs, it shifts the pattern by one position and starts again.

How it works

  1. Align pattern at index i = 0.
  2. Compare T[i+j] with P[j].
  3. If all pattern characters match, record i.
  4. Move to the next alignment, i + 1.

Complexity

Let text length be n and pattern length be m.

Worst-case time: O((n−m+1)m), commonly written O(nm). Extra space: O(1).

When to use

Good for short strings, small inputs, quick implementations, or when simplicity matters more than worst-case speed.

Python implementation

def naive_search(text, pattern):
    n, m = len(text), len(pattern)
    if m == 0:
        return list(range(n + 1))

    matches = []
    for i in range(n - m + 1):
        j = 0
        while j < m and text[i + j] == pattern[j]:
            j += 1
        if j == m:
            matches.append(i)
    return matches

print(naive_search("ABABABC", "ABABC"))  # [2]

This implementation defines an empty pattern as matching at every boundary from index 0 through n. Some libraries use different empty-pattern conventions.

4. KMP — Knuth–Morris–Pratt

KMP avoids rechecking text characters that are already known to match. It preprocesses the pattern into an LPS array: Longest Proper Prefix which is also a Suffix.

What LPS means

For each pattern position, LPS stores the length of the longest proper prefix of the pattern prefix that is also its suffix. “Proper” means it is shorter than the whole substring.

Why it helps

After a mismatch, KMP uses the LPS value to shift the pattern intelligently instead of moving all the way back to its first character.

Complexity

Preprocessing: O(m). Search: O(n). Total time: O(n + m); extra space: O(m).

KMP Python implementation

def build_lps(pattern):
    lps = [0] * len(pattern)
    length = 0
    i = 1

    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length:
            length = lps[length - 1]
        else:
            lps[i] = 0
            i += 1
    return lps

def kmp_search(text, pattern):
    if not pattern:
        return list(range(len(text) + 1))
    lps = build_lps(pattern)
    matches = []
    i = j = 0

    while i < len(text):
        if text[i] == pattern[j]:
            i += 1
            j += 1
            if j == len(pattern):
                matches.append(i - j)
                j = lps[j - 1]
        elif j:
            j = lps[j - 1]
        else:
            i += 1
    return matches

5. Rabin–Karp (rolling hash)

Rabin–Karp compares hash values for the pattern and each text window. If the hashes differ, the strings cannot match. If hashes match, it checks the actual characters because two different strings can have the same hash (a collision).

Basic steps

  1. Calculate the pattern hash.
  2. Calculate the hash of the first text window.
  3. Slide the window and update its hash efficiently.
  4. When hashes match, verify the characters.

Complexity

Expected/average behavior is often O(n + m) with a suitable hash and limited collisions. Worst case can be O(nm) due to collisions and verification.

When to use

Useful for searching many patterns, plagiarism-style matching, and comparing multiple windows. Hash design and collision checks matter.

Educational Python implementation

def rabin_karp(text, pattern):
    n, m = len(text), len(pattern)
    if m == 0:
        return list(range(n + 1))
    if m > n:
        return []

    base, mod = 256, 1_000_000_007
    high = pow(base, m - 1, mod)
    p_hash = t_hash = 0

    for j in range(m):
        p_hash = (p_hash * base + ord(pattern[j])) % mod
        t_hash = (t_hash * base + ord(text[j])) % mod

    matches = []
    for start in range(n - m + 1):
        if p_hash == t_hash and text[start:start + m] == pattern:
            matches.append(start)
        if start < n - m:
            t_hash = (t_hash - ord(text[start]) * high) % mod
            t_hash = (t_hash * base + ord(text[start + m])) % mod
    return matches

This is an educational rolling-hash example, not a cryptographic hash. The final substring comparison prevents false-positive matches from hash collisions.
