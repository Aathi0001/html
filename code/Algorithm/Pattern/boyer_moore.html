Boyer–Moore Algorithm

Learn how Boyer–Moore skips sections of text by comparing the pattern from right to left.

1. What is Boyer–Moore?

Boyer–Moore is a string pattern-matching algorithm that searches for a pattern inside a larger text. Its key idea is to compare characters from right to left and use mismatches to shift the pattern forward intelligently.

Key idea

Use mismatches to skip unnecessary comparisons.

Remember: Naive search moves the pattern one position at a time. Boyer–Moore can often move it several positions.

2. The two main rules

Bad-character rule

When a mismatch occurs, inspect the mismatching text character. Shift the pattern so that the character's rightmost occurrence in the pattern lines up with it. If it does not occur in the pattern, shift past that character.

Good-suffix rule

If a suffix at the right end of the pattern has already matched before a mismatch, shift the pattern to align another occurrence of that suffix, or a suitable matching prefix.

This study guide implements the bad-character rule, which is a useful way to learn the core algorithm. The full Boyer–Moore algorithm combines bad-character and good-suffix shifts.

5. Python implementation — bad-character version

def boyer_moore_bad_character(text, pattern):
    n = len(text)
    m = len(pattern)

    if m == 0:
        return 0

    if m > n:
        return -1

    # Store the rightmost index of each pattern character.
    last = {}
    for i, char in enumerate(pattern):
        last[char] = i

    shift = 0

    while shift <= n - m:
        j = m - 1

        # Compare from right to left.
        while j >= 0 and pattern[j] == text[shift + j]:
            j -= 1

        # All pattern characters matched.
        if j < 0:
            return shift

        # The mismatching character in the text.
        bad_char = text[shift + j]

        # Shift enough to align its rightmost occurrence.
        # If absent, last.get returns -1.
        shift_amount = max(1, j - last.get(bad_char, -1))
        shift += shift_amount

    return -1


text = "ABAAABCD"
pattern = "ABC"

print(boyer_moore_bad_character(text, pattern))
# Output: 4
This is the Boyer–Moore bad-character variant, not the full algorithm with the good-suffix rule.

6. Complexity

SituationComplexity
Preprocessing the last-occurrence tableO(m)
Typical practical searchOften sublinear in the text length, because shifts skip characters.
Worst case for this simple bad-character implementationO(n × m)
Extra spaceO(k), where k is the number of distinct pattern characters stored.

The full Boyer–Moore algorithm uses both bad-character and good-suffix preprocessing and has stronger performance guarantees under the standard algorithmic formulation.

7. When should you use Boyer–Moore?

Useful when

  • The text is long.
  • The pattern is reasonably long.
  • Many mismatches can cause large shifts.
  • You need efficient practical string search.

Remember

  • Compare right to left.
  • Precompute character positions.
  • Use mismatches to skip alignments.
  • The full version also uses good-suffix shifts.

9. Quick self-test

1. Which direction does Boyer–Moore compare?

From right to left within the pattern.

2. What is the bad-character rule?

Shift the pattern to align the mismatching text character with its rightmost occurrence in the pattern, or shift past it if absent.

3. What is the good-suffix rule?

Use a suffix that already matched to determine a safe shift.

4. Does the code above implement both rules?

No. It implements only the bad-character rule.
