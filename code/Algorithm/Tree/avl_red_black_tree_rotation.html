1. The idea behind rotations

Why balance?

An ordinary BST can become a chain, making operations O(n). Balanced trees keep height logarithmic, so search and updates are O(log n).

Rotation preserves order

A rotation rearranges parent/child links but keeps the binary-search-tree ordering intact.

AVL vs Red-Black

AVL uses subtree heights and balance factors. Red-Black uses node colors, recoloring, and rotations to maintain its properties.

AVL balance factor: height(left) − height(right). A valid AVL node has balance factor −1, 0, or +1.

3. The four AVL imbalance cases

LL — Left Left

The inserted key is in the left subtree of the left child. Fix with one right rotation.

Example: 30,20,10.

RR — Right Right

The inserted key is in the right subtree of the right child. Fix with one left rotation.

Example: 10,20,30.

LR — Left Right

The inserted key is in the right subtree of the left child. Left-rotate the left child, then right-rotate the unbalanced node.

Example: 30,10,20.

RL — Right Left

The inserted key is in the left subtree of the right child. Right-rotate the right child, then left-rotate the unbalanced node.

Example: 10,30,20.

AVL insertion performs ordinary BST insertion, updates heights while returning up the recursion, then applies the appropriate rotation at the first unbalanced node.

5. Red-Black tree rules

  1. Every node is red or black.
  2. The root is black.
  3. Every NIL/empty leaf is treated as black.
  4. A red node cannot have a red child.
  5. Every path from a node to descendant NIL leaves has the same number of black nodes.

Parent is black

No red-red violation; the inserted node needs no further fix.

Parent and uncle are red

Recolor parent and uncle black, grandparent red, then continue upward.

Parent red, uncle black

Align a triangle with a rotation if needed, then rotate at the grandparent and recolor.

6. Python: AVL rotation helpers

def right_rotate(y):
    x = y.left
    middle = x.right
    x.right = y
    y.left = middle
    # Update the lower node first
    y.height = 1 + max(height(y.left), height(y.right))
    x.height = 1 + max(height(x.left), height(x.right))
    return x  # New subtree root

def left_rotate(x):
    y = x.right
    middle = y.left
    y.left = x
    x.right = middle
    x.height = 1 + max(height(x.left), height(x.right))
    y.height = 1 + max(height(y.left), height(y.right))
    return y  # New subtree root

Time complexity for search, insert, and delete is O(log n) in AVL and Red-Black trees. AVL is more strictly balanced; Red-Black often needs fewer rotations during updates. This lesson simulates insertion; Red-Black deletion fix-up has additional cases.
