Lowest Common Ancestor (LCA)

The Lowest Common Ancestor of two nodes is the deepest node in a tree that is an ancestor of both. A node can count as its own ancestor. Learn the recursive idea, edit the tree and targets, then step through the algorithm.

Binary treeRecursionStep-by-step dry runPython

1. What does “lowest common ancestor” mean?

Ancestor

A node above another node on the path toward the root. A node is also considered an ancestor of itself.

Common ancestor

A node that is an ancestor of both target nodes.

Lowest / deepest

Of the common ancestors, choose the one farthest from the root—the one closest to both targets.

In the example tree, the LCA of D and E is B. The LCA of D and G is A. A is a common ancestor of D and E too, but B is lower (deeper), so B is the answer.

3. The recursive idea, in plain English

  1. If the current node is empty, return null.
  2. If the current node is either target p or q, return that node.
  3. Search the left subtree and save its result as left.
  4. Search the right subtree and save its result as right.
  5. If both results are non-null, one target was found on each side. The current node is the LCA.
  6. Otherwise return whichever side is non-null. If both are null, return null.
Key insight: the first node where the left recursion finds one target and the right recursion finds the other is the lowest common ancestor. This standard version assumes both target nodes exist in the tree.

4. Python solution

def lowest_common_ancestor(root, p, q):
    # Empty subtree: neither target found here
    if root is None:
        return None

    # Current node is one of the targets
    if root == p or root == q:
        return root

    # Ask both subtrees to search for the targets
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)

    # Targets are found on opposite sides
    if left is not None and right is not None:
        return root

    # Otherwise pass the result found by either side upward
    return left if left is not None else right

Time complexity

O(n) in the worst case. The algorithm may inspect every node once.

Space complexity

O(h) recursive call stack, where h is tree height. Worst case: O(n); balanced tree: O(log n).

This code uses node identity / references for p and q, as is common in coding-interview problems. The simulator uses unique text labels to represent node identity.

5. Follow one dry run

For targets D and E, recursion explores the left subtree of A. D returns itself, E returns itself, and B receives non-null results from both sides. So B returns as the LCA. A then passes B upward.

Targets in same subtree

Example D and E: their LCA is B, not A, because B is the deepest shared ancestor.

Targets across subtrees

Example D and G: one target is in A's left subtree and the other is in its right subtree, so A is the LCA.

One target is the ancestor

If p is B and q is D, the answer is B. The algorithm returns immediately when it reaches B.
