Tree Traversals

A tree can store data hierarchically. Traversal means visiting its nodes in a defined order. Here you can edit a tree, choose a traversal, and move through every visit one step at a time.

3. The four main traversals

Preorder: Root → Left → Right

Visit a node before traversing its children. Useful for copying/serializing a tree and prefix expressions.

A, B, D, E, C, F, G

Inorder: Left → Root → Right

Visit left subtree, then node, then right subtree. In a binary search tree, this gives values in sorted order.

D, B, E, A, F, C, G

Postorder: Left → Right → Root

Visit children before their parent. Useful when deleting a tree or evaluating expression trees bottom-up.

D, E, B, F, G, C, A

Level order

Visit one level at a time, from left to right. It uses a queue and is also called breadth-first traversal.

A, B, C, D, E, F, G

4. Python implementations

Each recursive traversal takes O(n) time because every node is visited once. The recursive methods use call-stack space proportional to tree height, O(h); in the worst case, h = n. Level order uses a queue that can hold up to O(n) nodes.

from collections import deque

class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right

def preorder(root):
    if root is None:
        return
    print(root.value)       # Root
    preorder(root.left)     # Left
    preorder(root.right)    # Right

def inorder(root):
    if root is None:
        return
    inorder(root.left)      # Left
    print(root.value)       # Root
    inorder(root.right)     # Right

def postorder(root):
    if root is None:
        return
    postorder(root.left)   # Left
    postorder(root.right)  # Right
    print(root.value)      # Root

def level_order(root):
    if root is None:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.value)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)

5. Dry-run checklist

  • Identify the root and each node's left/right children.
  • For preorder, record the root immediately before going left.
  • For inorder, finish the left subtree before recording the root.
  • For postorder, record the root only after both subtrees are complete.
  • For level order, use a queue: remove the front node, visit it, then add its children left-to-right.
Remember: the tree structure stays the same. Only the order in which nodes are visited changes.
