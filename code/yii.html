Module 1 - Introduction: Yii Fundamentals

Yii is one of the most popular PHP frameworks used for developing modern, secure, high-performance web applications. Before learning controllers, models, ActiveRecord, REST APIs, and advanced Yii features, it is important to understand what Yii is, why it exists, and what problems it solves.

1. What is Yii?

Definition

Yii is an open-source, high-performance PHP framework designed for developing modern web applications quickly and efficiently.

The name Yii is an acronym for "Yes It Is". It represents simplicity, reliability, and efficiency. Yii follows the MVC (Model-View-Controller) architectural pattern and provides built-in components for database interaction, security, caching, authentication, routing, validation, and REST API development.

Yii is written entirely in PHP and is designed for developers who need to build large-scale applications with clean architecture and maintainable code.

Why does Yii exist?

In traditional PHP development, developers write everything manually:

  • Database connection code
  • SQL queries
  • Form validation
  • Authentication logic
  • URL routing
  • Security handling
  • Error handling

As applications grow, manually managing all these responsibilities becomes difficult. Code becomes repetitive, insecure, and hard to maintain.

Yii solves these problems by providing reusable components and a structured application architecture.

Real-world analogy

Imagine building a house.

Without a framework, you must manufacture every item yourself:

  • Make your own bricks
  • Create your own electrical system
  • Build your own doors
  • Create your own plumbing

With Yii, you receive a professional construction system where many common building blocks already exist. You focus on designing your application instead of rebuilding basic functionality.

Where is Yii used?

Yii is commonly used for:

  • Enterprise applications
  • Customer relationship management systems (CRM)
  • Content management systems (CMS)
  • E-commerce platforms
  • Business dashboards
  • REST APIs
  • Internal company applications
  • Data management systems

Internal working of Yii

When a user opens a Yii application:

  1. The browser sends an HTTP request.
  2. The web server executes Yii entry script.
  3. Yii creates the application object.
  4. Configuration files are loaded.
  5. Yii finds the required controller.
  6. The controller executes an action.
  7. The model communicates with the database.
  8. The view generates HTML output.
  9. The response is sent back to the browser.

2. History of Yii

Beginning of Yii

Yii was created by Qiang Xue, a Chinese software developer. Before creating Yii, he worked on another PHP framework called Prado.

While working with Prado, he identified several limitations:

  • Performance issues
  • Complex architecture
  • High learning curve
  • Limited flexibility

To solve these problems, he started developing Yii.

Definition

Real-world analogy

  4. The employee handles your request.
  5. You receive the final result.

Yii follows a similar process:

  • Entry script = Main gate

Definition

  • Notification ability.
